# Самозанятость: легализация приёма оплат SubPing

Доход от подписок (15 ₽/мес) для самозанятого — налог на профессиональный доход
(НПД): **4% от физлиц**, **6% от юрлиц**. Лимит — 2,4 млн ₽/год.
На каждый платёж от пользователя нужно сформировать **чек** и передать его в ФНС.

## 1. Зарегистрироваться как самозанятый (однократно, 15 минут)

1. Приложение **«Мой налог»** (ФНС) — по паспорту или через Госуслуги.
2. Подтвердите регистрацию — автоматически получите ИНН.
3. Готово: сможете формировать чеки и платить налог в этом приложении.

## 2. Как легализовать текущий флоу (кошелёк + «Перевод по кнопке»)

**ЮSelf — это НЕ сайт.** Отдельного адреса `yoomoney.ru/yoself` не существует.
ЮSelf — раздел **внутри личного кабинета кошелька** (настройки → «Самозанятым»),
и по практике он не даёт ничего сверх приложения «Мой налог». Поэтому:

**Вариант A (просто, без кода):** чеки вручную в «Мой налог».
- На каждую оплату 15 ₽ бот вам в Telegram шлёт уведомление (email, сумма) —
  это и есть триггер.
- В «Мой налог» → «Новый чек» → сумма 15 ₽ → «Доход от физлица» →
  комментарий с email пользователя → чек отправляется покупателю и в ФНС.
- Налог 4% платится автоматически в приложении.

## 3. Вариант B: ЮKassa с авто-чеками (РЕАЛИЗОВАНО в коде)

Код готов: создание платежа через API ЮKassa, редирект на платёжную страницу,
вебхук `payment.succeeded` → Premium + чек владельцу + подтверждение покупателю.
В запрос платежа передаётся `receipt` с email покупателя — это основа для
автоматического чека ФНС. Осталось сделать ручные шаги в кабинете ЮKassa:

1. **Зарегистрируйтесь как самозанятый** в «Мой налог» (см. раздел 1).
2. **Подключите ЮKassa** на https://yookassa.ru как самозанятый:
   - онлайн-регистрация по ИНН, договор без визита в офис;
   - требуется идентифицированный кошелёк ЮMoney;
   - укажите, что принимаете оплату как самозанятый (НПД) — так ЮKassa
     автоматически формирует чеки и отправляет их покупателю и в ФНС.
3. **Получите креды API** в личном кабинете ЮKassa:
   - **shopId** (номер магазина) и **секретный ключ** (API key).
4. **Включите вебхуки** в кабинете ЮKassa → «Настройки» → «Уведомления»:
   ```
   https://subtrack-api-jszq.onrender.com/api/payments/yookassa/notify
   ```
   Событие: `payment.succeeded` (можно все).
5. **Передайте мне shopId и секретный ключ** — пропишу в render_env.json,
   поставлю на Render и переключу `PAYMENT_MODE=yookassa`.

Комиссия ЮKassa: ~3,5% по картам, от 0,4% по СБП; без абонентской платы.
Деньги зачисляются на кошелёк/счёт в течение 1–2 рабочих дней.

## 4. Что уже автоматизировано в коде (сделано)

- **Чек владельцу**: при каждой оплате бот пишет владельцу в Telegram
  (`OWNER_TG_CHAT_ID`) — email, сумма, до какого числа активен Premium.
- **Пользователю**: при активации Premium бот пишет ему подтверждение
  (если привязан `telegram_chat_id`).
- **Лог платежей**: метаданные вебхука (operation_id, sender) сохраняются в БД;
  владелец видит список последних 100 платежей в разделе «Платежи» настроек
  (аккаунт с email, равным `OWNER_EMAIL`).
- **ЮKassa**: создание платежа + receipt (email, vat_code) + вебхук
  `payment.succeeded` + фолбэк-поллинг по `external_id`.

## 5. Переменные окружения на Render (задать вручную)

- `OWNER_TG_CHAT_ID` — ваш числовой ID в Telegram (узнать у @userinfobot).
- `OWNER_EMAIL` — email вашего аккаунта на сайте (тот, под которым входите как владелец).
- `YOOKASSA_SHOP_ID` — номер магазина в кабинете ЮKassa.
- `YOOKASSA_SECRET_KEY` — секретный ключ API ЮKassa.
- `PAYMENT_MODE` — `yookassa` (или `yoomoney` для перевода по кнопке).

Поставить: `scripts/render_env.ps1` добавляет переменные и перезапускает деплой,
либо вручную в Render dashboard → Environment → Save → Manual Deploy.

## Итог для налоговой

- Доход: платите 4% через ЮKassa/«Мой налог» автоматически.
- Чеки: авто (ЮKassa, receipt в каждом платеже) или вручную («Мой налог»).
- Контроль: лог в настройках сайта + Telegram-уведомления на каждый платёж.
