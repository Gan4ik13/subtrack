# ЮMoney: последний ручной шаг (2 минуты)

Единственное, что нельзя автоматизировать через API, — включение HTTP-уведомлений
в интерфейсе кошелька. Нужно сделать один раз.

## Шаги

1. Войдите в кошелёк: https://yoomoney.ru/wallet
2. **Настройки** (иконка шестерёнки) → **Уведомления** → **HTTP-уведомления**.
3. Нажмите **Создать** / включите уведомления.
4. **Адрес уведомлений (URL):**
   ```
   https://subtrack-api-jszq.onrender.com/api/payments/yoomoney/notify
   ```
5. Включите **«Отправлять уведомления о счетах, если плательщик пополнил ваш кошелёк»**
   (тип `p2p-incoming`).
6. **Пароль уведомлений:** задайте любой — это и есть `YOOMONEY_NOTIFY_SECRET`.
   ОБЯЗАТЕЛЬНО тот же, что установлен на Render (см. вывод `render_env.ps1`).
7. Сохраните. ЮMoney отправит тестовое уведомление — сервер ответит `200`, это нормально.

## Проверка

- Оплатите через форму → Premium должен активироваться мгновенно (вебхук).
- Фолбэк: если вебхук не дошёл, фронтенд сам опросит API через `YOOMONEY_TOKEN`
  (поллинг каждые 8 секунд) и активирует Premium.

## Где взять токен API (YOOMONEY_TOKEN)

- https://yoomoney.ru/oauth/authorize → пошаговая выдача токена (нужен доступ
  `account-info` + `operation-history`).
- Либо во вкладке «Приложения» настроек кошелька создать токен на просмотр истории.
